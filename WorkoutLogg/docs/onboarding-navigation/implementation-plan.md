# План: переносы онбординга и отзывчивая навигация

1. Проверить три страницы онбординга, регистрационные подписи и длинные русские строки. Заменить неограниченные горизонтальные контейнеры и чрезмерно широкие фиксированные колонки.
2. Показывать существующий индикатор на исходной странице до создания следующей; исключить повторные переходы, добавить измерение этапа Shell-навигации.
3. Уменьшить пересоздание визуальных элементов календаря. Проверить независимую загрузку данных профиля и ограничения виртуализации списков.
4. Собрать Android ARM64; выполнить доступные проверки на подключённом Samsung A51 и записать границы проверки.

Источник правды — текущая разметка. Дополнительные макеты и скриншоты запрошены, пока не предоставлены. Изменение бизнес-логики онбординга в задачу не входит.

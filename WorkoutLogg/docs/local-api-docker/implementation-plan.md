# План: локальный API и инфраструктура Docker

1. Исключить API из стандартного запуска Compose через профиль `api`.
2. Загружать `.env` рядом с `docker-compose.yml` для локального Development-запуска API; сохранить приоритет переменных окружения.
3. Использовать локальные опубликованные порты, пароль PostgreSQL и ключ JWT из общей конфигурации. Удалить резервный пароль `postgres`.
4. Включить Kafka и OpenSearch в профилях локального запуска.
5. Проверить Compose, сборку и запуск API с существующими контейнерами. Обновить README.

# План: запросы телефона к локальному API

1. Разделить выбор URL для Android-эмулятора и физического устройства; подключить телефон к localhost компьютера через ADB reverse.
2. Ограничить время ожидания запросов авторизации; восстанавливать форму регистрации / входа при ошибках.
3. Собрать Android ARM64 и проверить доступность локального API, затем задокументировать запуск.

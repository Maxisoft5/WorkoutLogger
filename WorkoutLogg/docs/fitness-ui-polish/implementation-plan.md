# План: фитнес-иконки, зоны нажатия и горизонтальная прокрутка

1. Создать семантический набор на встроенном Fluent System Icons; заменить декоративные emoji в навигации, статических экранах и динамических карточках.
2. Увеличить зоны маленьких действий минимум до 48×48, перенести обработчики с рисунка на контейнер там, где это необходимо.
3. Добавить видимые индикаторы переполнения и положения в горизонтальных фильтрах, сохранив виртуализацию списков.
4. Проверить Android ARM64, оставшиеся emoji и обработчики, записать ручной чек-лист.

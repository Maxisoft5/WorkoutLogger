# Проверка веб-версии — 27 сентября 2026

Проверки выполнены локально, на двух тестовых организациях с отдельными
схемами PostgreSQL. Реальные данные старого приложения не переносились.

- React: TypeScript и production-сборка Vite проходят.
- Сервер: 185 тестов прошли в обычном запуске.
- Отдельный запуск с PostgreSQL: все 6 TenancyTests прошли, включая повторные
  миграции четырёх контекстов и независимые записи с одинаковыми email/ID.
- API: токен и refresh token зала A отклоняются в B; неизвестный домен
  возвращает 404; участник не получает доступ к админке; владелец получает.
- Браузер: вход и восстановление сессии после перезагрузки; сохранение
  тренировки с двумя подходами и повторное открытие редактора.
- Админка: сохранённый черновик не меняет публичный контент; явная публикация
  меняет заголовок главной.
- Профиль: параметры тела сохраняются и отображаются на главной.
- На мобильной ширине 390 px проверены светлая и тёмная главная, переключение
  темы; горизонтального переполнения страницы нет. Навигация прокручивается.

Полный браузерный прогон бронирований, кабинета тренера и AI-запросов пока не
выполнен. Оплата и перенос локального журнала MAUI остаются отдельной работой.
Существующие предупреждения NuGet о Microsoft.OpenApi 2.0.0 и
System.Security.Cryptography.Xml 10.0.7 требуют обновления зависимостей.

## Абонементы и доступ

После добавления абонементов полный запуск с PostgreSQL: **193 теста прошли**.
Проверены повторное сканирование, одновременный вход через два считывателя,
запоздалый повтор выхода, лимиты и сохранение условий выданного абонемента.
На HTTP API также проверены запрет входа в зал по тарифу «только бассейн»,
продление срока при заморозке, запрет доступа замороженному абонементу,
серверные права и изоляция двух клубов. Физический считыватель не подключался.

Через браузер дополнительно проверены изменение дневного лимита тарифа,
выдача «9 + 3», вход по тестовому коду с ростом счётчика 0 → 1 и выход 1 → 0.
Личный кабинет показывает одно использованное посещение и 91 доступный день
заморозки. Мобильная страница 390 px не имеет горизонтального переполнения.
